# Project Layout

```text
.
├── CMakeLists.txt
├── build.sh
├── clean.sh
├── docs/
├── mkdocs.yml
└── src/
```

## Key Files

- `CMakeLists.txt`: CMake project definition.
- `build.sh`: configure/build helper for the C++ target.
- `clean.sh`: cleanup helper for build artifacts.
- `mkdocs.yml`: MkDocs site configuration.
- `docs/`: Markdown sources for project documentation.
