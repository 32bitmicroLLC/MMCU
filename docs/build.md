# Build And Run

## Requirements

- CMake 4.0 or newer
- C++20-capable compiler with module support
- Ninja (optional, auto-detected by `build.sh`)

## Build

```bash
./build.sh
```

Useful options:

- `./build.sh --clean`
- `./build.sh --type Debug`
- `./build.sh --jobs 8`
- `./build.sh --run`

## Clean

```bash
./clean.sh
```
